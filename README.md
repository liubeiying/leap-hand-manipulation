## 自由度对齐：最容易被忽略的一步

- URDF 里四指 distal 常用 `<mimic>` 从动关节，**MJCF 里没有这个概念**
- 不对齐会导致：仿真自由度 ≠ 真机可下发指令数，动作在真机上对不上
- **我的处理**：
  1. 明确哪些是真机可主动控制的自由度
  2. 仿真侧补全执行器
  3. 锁定从动关节，保证与真机指令一致

## 抓取动作开发流程（五步循环）

```
示教录制 → 参数整定 → 仿真预演 → 真机回放 → 触觉闭环
     ↑                                          │
     └──────────────────────────────────────────┘
```

- **示教录制**：人手带动 / 脚本示教，记录关节角序列
- **参数整定**：力度、速度、保持时间逐项标定
- **仿真预演**：MuJoCo 校验限位与碰撞
- **真机回放**：一键回放，观察稳定性
- **触觉闭环**：指尖数据回灌，修正力度与时序
