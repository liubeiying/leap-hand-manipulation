LEAP Hand 灵巧手的仿真搭建、抓取动作开发与真机部署记录。

## 关于这个仓库

这是**复现与工程记录，不是原创算法**：

| 内容 | 上游 |
|---|---|
| LEAP Hand 仿真 | LEAP_Hand_Sim（leap-hand） |
| LEAP Hand 控制 API | LEAP_Hand_API（leap-hand） |
| 模型与场景 | mujoco_menagerie（google-deepmind） |
| 人形参考 | humanoid-gym（roboterax） |

我做的事情是搭仿真、对齐模型自由度、开发抓取动作序列、做真机联调。标注「待补」的地方是还没做完实测的部分。

## 自由度对齐：最容易被忽略的一步

URDF 里四指 distal 常用 `<mimic>` 定义从动关节，**MJCF 里没有这个概念**。不对齐的结果是仿真自由度不等于真机可下发指令数，动作在真机上对不上。

我的处理：

1. 先明确哪些是真机可主动控制的自由度
2. 仿真侧补全执行器定义
3. 锁定从动关节，保证与真机指令一致

可下发自由度与关节对应关系：待补

## 硬件规格（官方公开参数）

| 项 | 参数 | 来源 |
|---|---|---|
| 自由度 | 16（全部直接驱动） | LEAP Hand 官方规格 / RSS 2023 论文 |
| 手指 / 每指关节 | 4 指 × 4 关节 | 同上 |
| 驱动器 | Dynamixel XC330-M288-T（12）+ XC330-M181-T（4） | 同上 |
| 整机重量 | 595 g | RSS 2023 论文 |
| 通信 | Dynamixel Protocol 2.0，USB 串口（`/dev/serial/by-id`） | 官方规格 |
| 反馈 | 位置、速度、电流 | 同上 |
| 控制模式 | PID 默认，支持速度 / 电流控制 | 同上 |
| SDK | Python、C++、ROS、ROS 2 | 同上 |
| 仿真资源 | URDF + Isaac Gym / Isaac Lab 环境 | 同上 |

> 注意：LEAP Hand 基础版本身**不带触觉传感**，触觉是外加模块（常见做法是加装 DIGIT 触觉传感器）。我做触觉相关工作时用的是加装触觉的版本，这一点在 [docs/03-硬件联调.md](docs/03-硬件联调.md) 里有说明。

## 抓取动作开发流程

```
示教录制 → 参数整定 → 仿真预演 → 真机回放 → 触觉闭环
     ↑                                          │
     └──────────────────────────────────────────┘
```

最后一步的触觉数据会回到参数整定。动作不是一次成型的，是迭代出来的。详见 [docs/02-抓取动作开发.md](docs/02-抓取动作开发.md)。

## 硬件联调

```
上位机脚本 → USB-485 / CAN FD 适配器 → FTDI 驱动 → 终端电阻 120Ω → 手指电机 + 触觉
```

| 现象 | 排查方向 | 处理 |
|---|---|---|
| 指令无响应 | 物理层：接线 / 终端电阻 | 从下往上查，不跳步 |
| 偶尔丢包 | 协议层：波特率、共地、CAN 采样点 | 待补 |
| 触觉读数漂移 | 传感层：零偏标定 | 滤波 + 每次上电跑标定 |
