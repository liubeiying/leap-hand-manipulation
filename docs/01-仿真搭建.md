## 自由度对齐

URDF 中四指 distal 常带 `<mimic>`，MJCF 无对应机制。处理方式：明确真机可主动控制的自由度 → 仿真侧补全执行器 → 锁定从动关节。

校验方式很朴素：**数一遍**仿真可控自由度数，必须等于真机可下发指令数。我第一次就是漏了这一步，动作在真机上完全对不上，回头查才发现差了几个自由度。

主动 / 从动分布：待补

仿真预演的价值不是"证明能抓起来"，而是提前暴露限位冲突和碰撞问题，省下真机试错的时间。真机时间比 GPU 时间贵得多。
