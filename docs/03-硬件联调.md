## 通信链路

```
上位机脚本 → USB-485 / CAN FD 适配器 → FTDI / 串口驱动 → 终端电阻 120Ω → 手指电机 + 触觉
```

| 层 | 检查项 | 工具 |
|---|---|---|
| 物理层 | 接线、终端电阻（CAN 总线两端 120Ω） | 万用表 |
| 驱动层 | 设备枚举、波特率 | `dmesg` / 设备管理器 |
| 协议层 | 帧格式、采样点 | 抓包 / 回读 |

## 排查顺序（我的固定流程）

1. **先确认物理层**：接线和终端电阻没问题时，才往上查
2. **再确认驱动层**：设备是否被正确枚举
3. **最后查协议层**：波特率、帧格式、采样点

> 不跳步、不猜测。**一次只改一个变量**，改完立刻验证。
