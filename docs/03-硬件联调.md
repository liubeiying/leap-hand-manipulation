# 硬件联调记录

真实硬件的排查记录。安全相关的条目优先于一切性能问题。

## 上电前自检

- [ ] 供电电压确认，接线前断电
- [ ] 法兰螺钉旋入深度符合要求（过长会顶坏内部结构）
- [ ] 上电前机械结构处于空载状态
- [ ] 首次动作前确认急停可达

## 通信链路

```
上位机脚本 → USB-485 / CAN FD 适配器 → FTDI / 串口驱动 → 终端电阻 120Ω → 手指电机 + 触觉
```

| 层 | 检查项 | 工具 |
|---|---|---|
| 物理层 | 接线、终端电阻（CAN 总线两端 120Ω） | 万用表 |
| 驱动层 | 设备枚举、波特率 | `dmesg` / 设备管理器 |
| 协议层 | 帧格式、采样点 | 抓包 / 回读 |

## 排查顺序

我固定的流程：**先物理层，再驱动层，最后协议层。**

不跳步、不猜测，一次只改一个变量，改完立刻验证。凭感觉改三个地方，最后就算通了也不知道是哪个起的作用，下次还会再踩一遍。
